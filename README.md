## 📌 Description
An AI-based web application that simulates real interview scenarios.  
Users can practice interview questions, get feedback, and analyze performance.

---

## 🚀 Features
✨ Role-based question generation  
✨ Answer evaluation system  
✨ 📊 Score & Feedback  
✨ 🧠 Personality Analyzer  
✨ 🔐 Login & Dashboard  
✨ 🎯 Progress tracking
